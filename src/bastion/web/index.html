      Methodology
      
          How Bastion decides
          
      
          
        
        
          The detectors decide the verdict and the risk score. Llama only writes a short explanation from the detector's evidence.
          A guard checks the text while it streams and stops it the moment it contradicts the verdict or invents a link or phone
          number; the deterministic template is shown instead. Llama can never change the verdict.
          
      
          
      
          
        
          #privacy
          Everything runs on this device: no cloud, no external APIs, no telemetry. History is a local SQLite file that can store only hashes, or be cleared at any time.
          
        
          #limitations
            
          
          • SMS model trained on the UCI SMS Spam Collection (older, English, mostly UK). Indian UPI/KYC scams are under-represented.
            • 
          
          • PhiUSIIL's legitimate URLs are all https://www. homepages, so the URL model sees only the host without scheme or www., tuned for about 2% false alarms. It catches roughly 3 in 4 phishing links in testing; path tricks are caught by rules.
            • 
          
          • Timings from the emulated twin are not Raspberry Pi 5 timings.
