          About Bastion
          
      
          
        
          How it works
          
        
        
          The detectors decide the verdict and risk score. Llama only writes a short explanation from the detector's evidence. A guard rejects any explanation that contradicts the verdict or invents links or phone numbers, and the deterministic template is shown instead. Llama can never change the verdict.
          
      
          
      
          
        
          Privacy
          Everything runs on this device. No cloud, no external APIs, no telemetry. History stays in a local SQLite file and can be set to store only hashes, or cleared at any time.
          
        
          Limitations
            
          
          • SMS model trained on the UCI SMS Spam Collection (older, English, mostly UK); Indian UPI/KYC scams are under-represented.
            • 
          
          • PhiUSIIL's benign URLs are all https://www. homepages, so the URL model only sees the host without scheme or www., tuned for about 2% false alarms. It catches roughly 3 in 4 phishing links in testing; path tricks are caught by rules.
            • 
          
          • Timings from the emulated twin are not Raspberry Pi 5 timings.
